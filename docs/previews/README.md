# Vistas previas aproximadas

Estas imágenes **no son capturas de Roblox Studio**. Las genera `tools/preview/` a partir de la escena real que construye el servidor (mismas piezas, posiciones, rotaciones y colores), con un renderizador simple: sin texturas de materiales, sin sombras proyectadas ni partículas, y con el terreno aproximado.

Sirven para revisar la composición y las proporciones entre fases. Studio se verá con más detalle: texturas de madera y piedra, iluminación, atmósfera, luciérnagas y pasto animado.
